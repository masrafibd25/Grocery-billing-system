# Grocery Billing System

A simple grocery billing program made with C.

I created this project while learning C programming. It helps calculate the total price of Rice and Oil based on their quantity and price.

## What Can This Program Do?

- Calculate the price of Rice.
- Calculate the price of Oil.
- Calculate the total price of both Rice and Oil.
- Take quantity and price from the user.
- Check if the quantity and price are greater than zero.
- Show the final bill.

## Built With

- C Programming Language
- `stdio.h` (for input and output)

## How to Run

**Step 1: Compile the program**

```bash
gcc grocery_billing.c -o grocery_billing
```

**Step 2: Run the program**

On Linux:

```bash
./grocery_billing
```

On Windows:

```bash
grocery_billing.exe
```
